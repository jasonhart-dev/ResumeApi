# Resume API (.NET 10)

A sample ASP.NET Core Web API built with .NET 10 that exposes resume data via REST endpoints.

## Endpoints
- GET /api/profile
- GET /api/skills
- GET /api/experience

## Tech Stack
- .NET 10
- ASP.NET Core
- C#
- Swagger / OpenAPI



## Purpose
This project demonstrates clean API design, DTO usage, and dependency injection
for interview and portfolio purposes.
